# Openfield Art Credits

## 2D!PIXX isometric characters

Openfield uses the following character sprite sheets at runtime:

- **Warrior (Animated Character | Isometric)** — player, grunt, and heavy visual base
- **Wizard (Animated Character | Isometric)** — fast-enemy visual base

Source pages:

- https://opengameart.org/content/warrior-animated-character-isometric
- https://opengameart.org/content/wizard-animated-character-isometric

The original sprite sheets are served from OpenGameArt.org and are not relicensed as part of the Drakeshard RPG source code. Openfield maps their four-direction idle/walk/attack frames to its game-local actor states. The procedural canvas rigs remain as fallback rendering and are original Drakeshard sample code.
